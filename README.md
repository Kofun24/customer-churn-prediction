# Customer Churn Prediction

This is a machine learning project that predicts whether a customer is likely to churn or not.

## Project Description

Customer churn means a customer stops using a company's service.  
In this project, historical customer data is used to train a machine learning model that predicts churn.

## Dataset

The dataset contains customer information such as:

- Age
- Total Purchase
- Account Manager
- Years as Customer
- Number of Sites
- Churn

## Technologies Used

- Python
- Jupyter Notebook
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Machine Learning Algorithm

Logistic Regression was implemented from scratch using:

- Sigmoid function
- Cost function
- Gradient descent

## Model Accuracy

The model achieved approximately 88.89% accuracy on the test data.
